# GAP par Caroline St-Pierre

## Positionnement

Une plateforme médicale humaine, visuelle et simple. Elle sert trois objectifs:

1. Comprendre la situation GAP en trois secondes.
2. Donner aux médecins une raison de revenir chaque jour.
3. Présenter le GMF comme un milieu de pratique moderne et attirant.

## Règles

- Aucun fond beige dominant.
- Aucun long paragraphe dans les écrans GAP.
- Les graphiques dominent le texte.
- Une seule action principale par écran.
- Aucun défilement sur les écrans desktop essentiels.
- Un médecin comprend son état, celui du GMF et son action en moins de trois secondes.
- Les données importantes restent visibles sans clic.
- Les portraits temporaires doivent être remplacés par les vraies photos professionnelles.
- Aucune animation.
- Maximum deux clics pour atteindre une information.

## Écran Mon GAP

- Portrait et nom.
- Progression des visites sous forme d’anneau.
- Comparaison simple avec le GMF.
- Nombre restant très visible.
- Une seule action: voir mes plages.

## Écran GAP pour tous

- Pourcentage collectif des plages publiées.
- Pourcentage collectif des visites admissibles.
- Répartition: atteints, proches, à suivre.
- Portraits de l’équipe.
- Une seule action: voir les médecins.

## Accessibilité

- Ne jamais communiquer un état uniquement par la couleur.
- Contraste élevé.
- Texte essentiel de 16 px minimum sur desktop.
- Boutons principaux de 44 px minimum.
